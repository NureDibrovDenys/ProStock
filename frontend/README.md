# ProStock — веб-панель

React 19 + TypeScript + Vite. Стилі — CSS Modules, дизайн-токени в `src/styles/tokens.css` (кольори з Figma).

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
```

Усі дані йдуть із бекенда: запити `/api/*` проксуються на `http://127.0.0.1:8000`
(змінити — `VITE_API_TARGET`). Бекенд запускається з папки `backend`:
`uvicorn app.main:app --port 8000`. Мок-даних у проєкті немає: якщо ендпоінт ще не
реалізований, сторінка покаже, якого саме запиту бракує.

Список ендпоінтів і формат JSON для бекенду — **[API.md](API.md)**.

Вхід за паролем вимкнений за замовчуванням; увімкнути — `VITE_AUTH_ENABLED=true`
(див. `.env.example`).

## Структура

```
src/
  api/          HTTP-клієнт, типи, виклики ендпоінтів (див. API.md)
  auth/         контекст сесії, захист маршрутів
  components/   NavBar, Button, Input, StatCard, діаграма, мапа (map/: геометрія, модель, рендер)
  hooks/        useViewport — зум і панорамування мапи
  pages/        екрани: Вхід, Головна, Співробітники, Новий співробітник, Склад, Стелаж, Конструктор
  styles/       токени та глобальні стилі
```

## Конструктор складу

Перенесений з прототипу тіммейта (`/warehouse/edit`). Одиниці — метри, крок сітки 0,5 м.

| Клавіша | Інструмент |
|---|---|
| V | вибір і переміщення |
| H / Пробіл / середня кнопка | рух полотна |
| W | контур приміщення: клік — вершина, Enter або клік на першу точку — замкнути |
| R | стелаж: клік — за пресетом, протягування — власний розмір |
| O | перешкода |
| I / S / U | зона приймання / зберігання / відвантаження |
| E | точка входу |
| Q (Shift+Q) | поворот обраного на 15° |
| Del | видалити обране |

Стелажі, що перетинаються з іншими стелажами чи перешкодами або виходять за контур,
підсвічуються червоним. «Зберегти» відправляє `PUT /warehouses/{id}/map`,
«Експорт JSON» завантажує ту саму мапу файлом.
