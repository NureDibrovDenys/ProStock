# ProStock — веб-панель

React 19 + TypeScript + Vite. Стилі — CSS Modules, дизайн-токени в `src/styles/tokens.css`.
Іконки — `lucide-react` (SVG).

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # перевірка типів + production-збірка
```

Запити `/api/*` проксюються на `http://127.0.0.1:8000` (змінити — `VITE_API_TARGET`).
Мок-даних немає: усі дані йдуть із бекенда.

## Авторизація

- access-токен зберігається лише в памʼяті JavaScript (не в `localStorage`);
- refresh-токен — httpOnly cookie, тому після перезавантаження сторінки сесія
  відновлюється запитом `POST /auth/refresh`;
- `AuthProvider` оновлює токен за 60 с до завершення, виходить при невдалому refresh,
  після `401` та синхронізує вихід між вкладками;
- недоступні за роллю дії приховані, маршрути захищені `RequirePermission`.

## Сторінки

| Маршрут | Призначення | Доступ |
|---|---|---|
| `/login` | вхід із валідацією полів | усі |
| `/` | головна: KPI складу | усі |
| `/products` | каталог: таблиця, CRUD, імпорт, експорт | усі (запис — за роллю) |
| `/employees`, `/employees/new` | користувачі | root / administrator |
| `/warehouse`, `/warehouse/edit` | склад і конструктор мапи (дані з БД) | усі / запис — за роллю |
| `/warehouse/racks/:code` | полиці стелажа | усі |

## Товари

- пошук (debounce 350 мс), фільтри за категорією та одиницею виміру, сортування, пагінація;
- створення/редагування в модальному вікні з валідацією полів і створенням категорії на місці;
- видалення з підтвердженням;
- імпорт CSV/XLSX через drag&drop із переглядом звіту: скільки створено/оновлено,
  таблиця помилок по рядках, вивантаження звіту CSV, шаблони файлів;
- експорт CSV та Excel з урахуванням активних фільтрів.
